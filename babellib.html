Babel Library

Babel Library is an android app that was made as a project for a university course. It was made in 3 days in Android Studio using Java.

Bug Reports/Feature Requests

Inspiration

The Type of Project

The project was restricted to being any kind of shopping application. I chose a Library app because I assumed it would be easy to implement. It would be easy for the user to see the product they bought in the app and even read the books if possible.

The Name

I drew a lot of inspiration for the name from Library of Babel (which is inspired by the Tower of Babel).

The design

I chose this design because i like minimalistic designs, also I like sharp edged designs. I ended up making a light mode (even though I wouldn't use it personally). Hey, some people like getting flashbanged I guess.

Process

I worked on this project solo for 3 days. I learnt a lot from the project that was not taught in class that I hope to use in the future.

FAQ

Does Babel store my info?

No! All your information is stored in a local database on your device. If you're skeptical, just don't put personal info in the app or check the source code.
